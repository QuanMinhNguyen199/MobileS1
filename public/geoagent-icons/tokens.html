Dùng trong code

  1. Trong Figma, chọn phần tử, đọc tên biến (Fill brand/brand), kiểu chữ (Body/Message) hoặc đổ bóng. Mô tả của component ghi sẵn cách gọi component React.
  2. Trong code, tìm token đó trên trang này và bấm để sao chép class: bg-brand, text-message, shadow-composer. Không gõ mã màu hay số px.
  3. Đồng bộ khi token đổi: plugin GeoAgent DS Builder → Tải tokens.json → chép đè tokens/geoagent.tokens.json → npm run tokens. Trang này tự cập nhật ở lần deploy sau.
  4. Nền tảng khác (iOS, Android, React Native): dùng file geoagent.tokens.json (chuẩn W3C DTCG) với công cụ như Style Dictionary.
Sinh tự động từ tokens/geoagent.tokens.json bởi npm run icons:export. Không sửa tay trang này.
